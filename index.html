Review the run as recorded: controls first, then the sample. Every result names the settings that produced it; the raw record stays available beside it.

Real data analysis

Open your experiment files and use MISSY’s normal analysis tools. Check the virtual runs you want to open. MISSY loads them automatically and opens the Control Panel.

Virtual runs

Run files

Every run started on the technician bench is filed here under its number and name. Runs of the same analysis share one SOP (same identity, same file). The list lives in this browser tab: download what you want to keep before you close it.

Analysis settings

Each assay is analysed on its own tubes and its own detection channel, with its own threshold. You can also drag the pink line in the amplification chart. Confirm changes to update the results from the raw record.

Output files

Open the .rdml in MISSY with its file picker. It carries the measured fluorescence of both channels, one target per method, the melt data, the programme and the Cq computed here. It is marked as simulated.
