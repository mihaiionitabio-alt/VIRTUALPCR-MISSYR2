Development data and local records

Instrument-export summary statistics and fitted curve profiles

The original review records 730 run files for curve-shape/control-variation summaries. The model also retains 71 late P-35S profile shapes. These private source records have no public dataset URL.

Model summaries are distinct from the user’s experiment files. No private local paths or raw run exports are published here.

Model implementation

Virtual control-chart histories

Built-in simulated teaching histories derived from local instrument-record summaries. These are training examples, not new real instrument experiments.
